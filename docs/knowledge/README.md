# База знаний: «Найти интересные идеи рендеринга»

Этот каталог — рабочая память проекта, актуализированная 27 октября 2026 года. Он фиксирует реализованные решения и границы их применимости, чтобы продолжение работы не зависело от истории чата или конкретного компьютера.

## Видение

Строить узнаваемый, цельный городской макет автоматически: покрытия, дороги, развязки, тоннели, железная дорога, здания, зелень, малые формы и набережные. Геометрия должна сохранять стыки и уровни; настройки внешнего вида должны быть управляемыми, а результат — одинаковым при повторной сборке.

Viewer служит и просмотрщиком большой сцены, и лабораторией материалов, освещения, воды и способов рендеринга. Цель не в максимальном количестве эффектов, а в ясном, приятном и отзывчивом изображении. Принятые пользователем цвета, модели и настройки сохраняются как явные пресеты.

## Как читать

1. `HANDOFF.md` — запуск, восстановление, правила продолжения.
2. `ARCHITECTURE.md` — код, данные, генерация и рендер.
3. `DECISIONS.md` — что пользователь утвердил и что нельзя случайно откатить.
4. `DEPLOYMENT.md` — Cloud.ru, GitHub Pages, контроль целостности.

## Что пока является направлением, а не готовой функцией

Перенос алгоритмов в Unreal Engine с PCG и редактируемыми сплайнами дорог обсуждался; готового UE-плагина нет. Для UE предполагаются другие модели деревьев. Расширение Москвы ещё на 2 км с каждой стороны было отложено ради эксперимента с Петербургом. Не считать эти задачи выполненными.

Данные 2ГИС и текущая система высот дают визуальный макет, не геодезическую гарантию. Нельзя объявлять местную проекцию Петербурга официальной городской системой координат только из-за исторического имени поля `boundsMSK`.
