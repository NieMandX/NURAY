# База знаний: «Найти интересные идеи рендеринга»

Этот каталог — рабочая память проекта, актуализированная 10 ноября 2026 года. Он фиксирует реализованные решения и границы их применимости, чтобы продолжение работы не зависело от истории чата или конкретного компьютера.

## Видение

Строить узнаваемый, цельный городской макет автоматически: покрытия, дороги, развязки, тоннели, железная дорога, здания, зелень, малые формы и набережные. Геометрия должна сохранять стыки и уровни; настройки внешнего вида должны быть управляемыми, а результат — одинаковым при повторной сборке.

Viewer служит и просмотрщиком большой сцены, и лабораторией материалов, освещения, воды и способов рендеринга. Цель не в максимальном количестве эффектов, а в ясном, приятном и отзывчивом изображении. Принятые пользователем цвета, модели и настройки сохраняются как явные пресеты.

## Как читать

1. `HANDOFF.md` — запуск, восстановление, правила продолжения.
2. `ARCHITECTURE.md` — код, данные, генерация и рендер.
3. `DECISIONS.md` — что пользователь утвердил и что нельзя случайно откатить.
4. `DEPLOYMENT.md` — Яндекс Cloud, GitHub Pages, контроль целостности.

## Что пока является направлением, а не готовой функцией

Перенос алгоритмов в Unreal Engine с PCG и редактируемыми сплайнами дорог обсуждался; готового UE-плагина нет. Для UE предполагаются другие модели деревьев. Сборка Москвы до максимального сохранённого квадрата 10 × 10 км завершена и проверена во viewer 10.11.2026. Полный экспорт — glTF + один BIN (11,53 ГБ, сжатая пара 3,78 ГБ), 33 объекта и 362 328 инстансов. Начальный сектор 3 × 3 км вокруг выбранного пользователем участка: он использует 169 готовых тайлов с небольшим запасом по границам. Соседние части добавляются вручную по 1 км; перемещение камеры не загружает остальную карту. Данные опубликованы в Яндекс Cloud; GitHub Pages по умолчанию открывает выбранный сектор. Полный локальный просмотр работает в WebGPU-растеризации; текущего лимита четырёх GPU-буферов недостаточно для трассировки всего расширенного участка.

Данные 2ГИС и текущая система высот дают визуальный макет, не геодезическую гарантию. Нельзя объявлять местную проекцию Петербурга официальной городской системой координат только из-за исторического имени поля `boundsMSK`.
