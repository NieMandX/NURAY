# Публикация и хранение

С 08.11.2026 рабочее хранилище проекта — **Яндекс Cloud**. Код и интерфейс публикуются на GitHub Pages. Cloud.ru сохранён как прежняя инфраструктура, но текущий viewer и восстановление файлов к нему не обращаются. История прежней публикации и сравнений — [DEPLOYMENT-20261107.md](DEPLOYMENT-20261107.md).

## Размещение

- Репозиторий: `https://github.com/NieMandX/NURAY`, ветка `main`.
- Viewer: `https://niemandx.github.io/NURAY/`.
- Публикуемая папка: `moscow-fidelity/web-preview/`.
- Открытые runtime-файлы: `https://storage.yandexcloud.net/nuray-assets-niemandx/`.
- Неизменяемый выпуск: `assets-moscow-style-20261024-r14/`.
- Закрытый архив: бакет `nuray-backups-niemandx`, ключ `backups/nuray-moscow-build-20261027.tar.gz`.

Петербургская сцена по-прежнему локальная; миграция переносит весь опубликованный московский выпуск, который обслуживался Cloud.ru. Геометрия, инстансы, региональные пресеты и ключи пользовательских настроек не изменены.

`config.json → assetBase` задаёт Яндекс для каталогов, текстур, контейнера тайлов и BVH. `assetDelivery` выбирает сжатую доставку. Старый параметр `mirror=yandex` совместим и указывает на тот же основной объект Яндекса; автоматического возврата к Cloud.ru нет.

## Доступ и HTTP

`nuray-assets-niemandx` содержит только публичные ассеты; чтение объектов разрешено, анонимное перечисление и изменение запрещены. **Не загружать сюда закрытые архивы, ключи и приватные исходники.** `nuray-backups-niemandx` целиком закрыт для анонимного чтения, перечисления и изменения.

Класс хранения — `STANDARD`. Лимиты вместимости: 10 ГиБ для ассетов и 5 ГиБ для резервных копий. CDN не подключён.

CORS публичного бакета разрешает только GET/HEAD для GitHub Pages и локального viewer на 8765/8776 (`127.0.0.1` и `localhost`). Допускаются Range и Content-Type; доступны Content-Length, Content-Range, Content-Encoding и ETag. Max-age CORS — 3600 с.

Runtime-объекты получают `Cache-Control: public,max-age=31536000,immutable`. **Не назначать `.gz` и `meshes.pack` HTTP Content-Encoding**: viewer распаковывает данные самостоятельно. Для GLB используется `model/gltf-binary`, JSON — `application/json`; Range должен возвращать 206 и точный Content-Range.

## Проверка и восстановление

```sh
python3 scripts/verify_cloud.py
python3 scripts/verify_delivery.py --require-cache
python3 scripts/restore_assets.py --mode all
python3 scripts/restore_assets.py --mode all --check-only
```

Проверки используют актуальные Яндекс-адреса из manifest/config. Первая проверяет 202 объекта, CORS, размеры и три диапазона контейнера. Вторая — три gzip-компаньона и контрольные диапазоны. Восстановление сверяет SHA-256 файлов и поддерживает продолжение загрузки. Контейнер остаётся рядом с распакованными мешами; учесть дополнительные 848 МБ на диске.

Для восстановления сборки скачать закрытый архив и его manifest через авторизованную консоль Яндекса либо настроенный `yc`:

```sh
yc storage s3 cp s3://nuray-backups-niemandx/backups/nuray-moscow-build-20261027.tar.gz ./nuray-moscow-build-20261027.tar.gz
shasum -a 256 nuray-moscow-build-20261027.tar.gz
tar -xzf nuray-moscow-build-20261027.tar.gz
```

Распаковывать в корень клона после проверки SHA-256. Для локального просмотра пересборка не нужна: `python3 scripts/serve.py`, затем `http://127.0.0.1:8776/`.

## Новые выпуски

Сначала загрузить новый versioned-префикс, проверить его, затем переключить config и manifest и опубликовать код. GLB, BVH, поверхности, текстуры и каталог должны принадлежать одному выпуску. Не перезаписывать несовместимой геометрией immutable-объект.

Предпочтительна уже авторизованная CLI/Cloud Shell. Для локальных возобновляемых multipart-передач имеется `scripts/upload_cloud.py`; defaults — endpoint Яндекса, бакет ассетов, класс STANDARD. Требуется boto3 и настроенный SDK-профиль либо отдельный файл ключа с правами 0600. Секреты не включать в Git, команды и логи. Новые ключи при переносе не создавались.

```sh
python3 scripts/upload_cloud.py /path/to/meshes.pack \
  --key assets-NEW/meshes.pack --sha256 EXPECTED_SHA256 \
  --cache-control 'public,max-age=31536000,immutable'
```

Для закрытых архивов обязательно указать `--bucket nuray-backups-niemandx` и не задавать публичный Cache-Control. Загрузчик проверяет SHA-256, Content-MD5 частей, их ETag, итоговый размер и фактические диапазоны. Несовпадающий существующий объект не перезаписывает. Прерванную передачу продолжает из `.local/uploads/`.

Lossless-компаньоны готовятся через `scripts/prepare_delivery.py`; размеры и SHA-256 — `../delivery-moscow-20261107.json`. Потоковая распаковка GLB и пакетные Range-запросы не меняют геометрию. Настройки пользователя остаются привязаны к прежнему ключу каталога.
